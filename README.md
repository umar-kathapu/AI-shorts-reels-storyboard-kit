# AI Shorts and Reels Script and Storyboard Kit

## Project No: 50

### Project Overview

This project focuses on using Artificial Intelligence to create short-form video content for college students. The project demonstrates an AI-assisted workflow for generating video ideas, scripts, storyboards, and a final short video.

### Niche

**AI & Student Productivity**

### Target Audience

College Students (18–24 years)

### Platforms

* Instagram Reels
* YouTube Shorts

### Video Format

* Aspect Ratio: 9:16 Vertical
* Duration: Approximately 41 seconds

## Project Objectives

* Generate engaging AI and student productivity video ideas.
* Develop short-form video scripts using AI.
* Create scene-by-scene storyboards.
* Produce an actual short video using AI tools.
* Verify content for factual and copyright issues.
* Compare the workflow before and after AI assistance.
* Collect and review audience feedback.

## Selected Video Ideas

1. AI Prompt Formula Every Student Should Know
2. 5 AI Mistakes Students Should Avoid
3. My 10-Minute AI Workflow for College Work

## Final Video

### Title

**AI Prompt Formula Every Student Should Know**

The video explains a simple prompting structure using:

**Role + Task + Context + Output Format**

It demonstrates how students can write clearer prompts when working with AI tools.

## AI Tools Used

| Tool    | Purpose                                           |
| ------- | ------------------------------------------------- |
| Gemini  | Video idea generation and script development      |
| Gemini  | Storyboard and content planning                   |
| Ayka AI | AI-generated short video                          |
| Canva   | Video editing, text, transitions and presentation |

## Content Verification and Responsible AI

* The project avoids unsupported statistics and exaggerated claims.
* AI-generated content was reviewed before final use.
* No personal or confidential information was included.
* No copyrighted movie clips, celebrity footage, or copied social-media videos were used.
* The prompting formula is presented as a practical method, not as a guaranteed formula for better results.
* The final content was reviewed for responsible AI usage and copyright concerns.

## Before and After AI Assistance

| Before AI Assistance                      | After AI Assistance                      |
| ----------------------------------------- | ---------------------------------------- |
| Ideas were generated manually             | AI-assisted idea generation              |
| Script writing required more time         | AI helped structure the script quickly   |
| Storyboard planning was manual            | AI-assisted scene planning               |
| Video creation required separate planning | AI-generated video simplified production |
| Content required more editing effort      | Faster workflow with AI + Canva          |

## Audience Feedback

The video was reviewed for clarity, usefulness, visual quality, and engagement. The main feedback was to keep the content simple, use readable on-screen text, and maintain a fast pace suitable for short-form video.
